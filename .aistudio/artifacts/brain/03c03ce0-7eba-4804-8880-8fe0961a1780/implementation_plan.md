# خطة تدقيق وتنفيذ الشريط السفلي وفق وثيقة التعليمات لكل الصلاحيات

استجابةً لتوجيهك الدقيق: **«حسب التعليمات لكل الصلاحيات»**، تم مراجعة وثيقة الشروط والتعليمات الأصلية بدقة متناهية، وبناء خريطة الشريط السفلي بحيث يطابق كل تبويب لكل دور من الأدوار العشرة اختصاصاته وصلاحياته الحقيقية المنصوص عليها في وثيقة النظام دون زيادة أو نقصان.

---

| الدور (Role) | عدد التبويبات | ترتيب التبويبات في الشريط السفلي | الوظيفة المعتمدة وفق وثيقة التعليمات |
| :--- | :---: | :--- | :--- |

| **2. الباحث المسجل** (`seeker`) | 5 | `الرئيسية` • `البحث` • `المفضلة` • `تذاكر الدعم` • `حسابي` | تصفح كامل، إدارة المفضلة الشخصية، تذاكر الدعم والاستفسارات، وإدارة الحساب. |

| **5. وكيل المنشأة العقارية** (`org_agent`) | 5 | `الرئيسية` • `إعلاناتي` • `[ أضف إعلان ➕ ]` • `البحث` • `حسابي` | إنشاء وتعديل الإعلانات المسندة إليه فقط ضمن المنشأة، ومتابعة حالاتها. |

| **7. مسؤول التحقق** (`verifier`) | 5 | `الرئيسية` • `لوحة التحقق` • `البحث` • `المعايير` • `حسابي` | فحص الهويات والسجلات والبصائر، منح شارات التوثيق المعتمدة داخلياً وتوثيق المصدر. |
| **8. مسؤول البلاغات** (`reporter_admin`) | 5 | `الرئيسية` • `لوحة البلاغات` • `البحث` • `السياسات` • `حسابي` | فحص الشكاوى، معاينة نسخة الإعلان وقت البلاغ، اتخاذ قرار التجميد أو الإنذار أو الحفظ. |
| **9. ممثل الدعم الفني** (`support`) | 5 | `الرئيسية` • `تذاكر الدعم` • `البحث` • `الأسئلة الشائعة` • `حسابي` | استقبال تذاكر المستخدمين، الرد، التصعيد، وإغلاق التذاكر المكتملة. |

## 1. تفصيل كل دور وفق شروط وثيقة النظام الأصلية

### 1. الزائر غير المسجل (`visitor`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية التفاعلية للعقارات المنشورة النشطة في صنعاء وعدن وبقية المحافظات.
* **التبويب 2: البحث (`search`):** البحث بالكلمات والحي والمحافظة والتصنيفات والأسعار.
* **التبويب 3: المساعدة (`help`):** إرشادات وسياسات النشر والمعايير اليمنية.
* **التبويب 4: تسجيل الدخول (`account`):** نافذة تسجيل الدخول برقم الهاتف لإنشاء حساب جديد.
* *(حجب كامل لـ: المفضلة، أضف إعلان، المسودات، لوحات الإشراف)*.

### 2. المستخدم المسجل والباحث (`seeker`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: البحث (`search`):** استكشاف وفلترة العقارات.
* **التبويب 3: المفضلة (`favorites`):** قائمة عقاراته المحفوظة مع شارة عدد العقارات.
* **التبويب 4: تذاكر الدعم (`support`):** إرسال استفسارات وبلاغات وتذاكر ومتابعة الردود.
* **التبويب 5: حسابي (`account`):** الملف الشخصي، رقم الهاتف، وإعدادات الجلسة.

### 3. المعلن الفرد الموثق (`advertiser`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: إعلاناتي (`my_ads`):** تتبع المسودات، قيد المراجعة، يحتاج استكمال، المنشور، المرفوض، والموقوف مع معرفة الأسباب.
* **التبويب 3: أضف إعلان (`wizard` - زر مركزي بارز):** معالج إضافة الإعلانات العقارية اليمني.
* **التبويب 4: المفضلة (`favorites`):** العقارات المحفوظة.
* **التبويب 5: حسابي (`account`):** بيانات المعلن وشارات التوثيق الممنوحة.

### 4. مدير المنشأة العقارية (`org_manager`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: المنشأة (`organization`):** إدارة ملف المنشأة، السجل التجاري، دعوة وتفعيل الوكلاء، وإسناد العقارات.
* **التبويب 3: أضف إعلان (`wizard` - زر مركزي بارز):** إنشاء إعلان معتمد للمنشأة.
* **التبويب 4: إعلاناتي (`my_ads`):** متابعة كافة إعلانات منشأته ووكلائه وإحصاءاتها.
* **التبويب 5: حسابي (`account`):** حساب مدير المنشأة.

### 5. وكيل المنشأة العقارية (`org_agent`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: إعلاناتي (`my_ads`):** الإعلانات المسندة إليه فقط ضمن المنشأة ومتابعة حالاتها.
* **التبويب 3: أضف إعلان (`wizard` - زر مركزي بارز):** إضافة عقار مفوض به باسم المنشأة.
* **التبويب 4: البحث (`search`):** فحص ومقارنة السوق.
* **التبويب 5: حسابي (`account`):** ملف الوكيل وارتباطه بالمنشأة.

### 6. مراجع المحتوى (`moderator`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: مراجعة الإعلانات (`moderation`):** طابور المراجعة لاتخاذ قرار (اعتماد ونشر / رفض مسبب / طلب استكمال بيانات).
* **التبويب 3: البحث (`search`):** استكشاف وفحص تكرار الإعلانات وجودتها.
* **التبويب 4: سياسات النشر (`help`):** ضوابط ومعايير المحتوى المقبولة.
* **التبويب 5: حسابي (`account`):** ملف المراجع.

### 7. مسؤول التحقق والمطابقة (`verifier`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: لوحة التحقق (`verification`):** مراجعة طلبات التحقق، فحص وثائق الهوية والبصائر والسجلات داخلياً، ومنح شارات التوثيق المسببة.
* **التبويب 3: البحث (`search`):** فحص العقارات الموثقة.
* **التبويب 4: المعايير (`help`):** الأدلة الإجرائية للتحقق العقاري باليمن.
* **التبويب 5: حسابي (`account`):** ملف مسؤول التحقق.

### 8. مسؤول البلاغات والنزاعات (`reporter_admin`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: لوحة البلاغات (`reports`):** فحص قضايا النزاع والاحتيال ومعاينة نسخة الإعلان وقت البلاغ واتخاذ قرار التجميد أو الإنذار أو الحفظ.
* **التبويب 3: البحث (`search`):** استعراض الإعلانات المشكوك فيها.
* **التبويب 4: السياسات (`help`):** قواعد حماية المستهلك العقاري.
* **التبويب 5: حسابي (`account`):** ملف مسؤول البلاغات.

### 9. ممثل الدعم الفني (`support`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: تذاكر الدعم (`support`):** استعراض التذاكر، الرد المباشر، وتصعيد المشاكل.
* **التبويب 3: البحث (`search`):** الاستعلام عن بيانات العقارات لمساعدة العملاء.
* **التبويب 4: الأسئلة الشائعة (`help`):** قاعدة المعرفة والإرشادات.
* **التبويب 5: حسابي (`account`):** ملف ممثل الدعم.

### 10. مدير النظام العام (`system_admin`)
* **التبويب 1: الرئيسية (`home`):** الخريطة الحية.
* **التبويب 2: لوحة الإدارة (`admin`):** إدارة الأدوار، الحسابات، تصنيفات العقارات، والمحافظات.
* **التبويب 3: سجل التدقيق (`audit_log`):** سجل التدقيق الرقابي غير القابل للتعديل لكافة العمليات الحساسة.
* **التبويب 4: المراجعة (`moderation`):** الإشراف على طوابير الاعتماد والمراجعة.
* **التبويب 5: حسابي (`account`):** ملف المشرف العام.

## 2. خطوات التنفيذ البرمجي الدقيق
1. تحديث `src/components/BottomNavBar.tsx` ليعكس هذه المصفوفة الحصرية المكونة من 10 حالات دقيقة لا تشترك بأي خلط أو قيم افتراضية غير مدروسة.
2. دعم التبديل السلس بين الصفحات في `src/App.tsx` مع تأمين كل صفحة بـ `ProtectedRoute` المناسب لها تماماً.
3. التأكد من ظهور شارات الإشعارات والعدد (مثل عدد العقارات في المفضلة للباحث والمعلن، وعدد التذاكر أو الإعلانات المعلقة للمشرفين).
4. التحقق والتشغيل واختبار جميع الأدوار عبر أداة المحاكاة.
